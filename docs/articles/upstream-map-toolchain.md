# Upstream Map Toolchain

The upstream map catalog centralizes the source scope, parser identity, classification policy, output files, and semantic check command for 72 source maps, including Cudev's partial callable map and template/macro source inventory. Its schema is `compatibility/upstream-map-catalog.schema.json`, and the checked catalog is `compatibility/upstream-map-catalog.json`.

上游映射 catalog 集中记录 72 个源码映射（含 Cudev 的部分 callable map 与模板/宏源清单）的源码范围、parser 身份、分类策略、输出文件和语义检查命令。其 schema 是 `compatibility/upstream-map-catalog.schema.json`，已审计的 catalog 是 `compatibility/upstream-map-catalog.json`。

Generated family inventories use UTF-8 without BOM, LF line endings, and a final newline. The shared contrib, XPhoto, and XImgProc generators hash those exact canonical bytes, so Git's LF checkout policy preserves the recorded hashes on Windows and other hosts. The catalog guard checks every family inventory and rejects CRLF, BOM, and missing-newline fixtures.

生成的 family inventory 统一使用无 BOM 的 UTF-8、LF 换行和末尾换行。共享 contrib、XPhoto 和 XImgProc 生成器对这些固定字节计算哈希，确保 Git 的 LF 检出策略不会改变记录的哈希。catalog guard 校验全部 family inventory，并拒绝 CRLF、BOM 和缺少末尾换行的反例。

Regenerate the catalog after an intentional map-surface update:

```powershell
pwsh -NoProfile -File .\scripts\New-UpstreamMapCatalog.ps1
```

Run the configured suite:

```powershell
pwsh -NoProfile -File .\scripts\Test-UpstreamMapCatalog.ps1
```
