# 15 Sparse Optical Flow / 稀疏光流

The workflow detects Shi-Tomasi corners in one frame, tracks them with pyramidal Lucas-Kanade, and draws motion arrows for valid points.

本案例在前一帧中检测 Shi-Tomasi 角点，使用金字塔 Lucas-Kanade 跟踪，并为有效点绘制运动箭头。

```powershell
dotnet run --project .\samples\Video\02.OpticalFlow\OpticalFlow.csproj -c Release -- .\artifacts\tutorial-15
```

The status and error arrays are part of the result contract. Always discard points whose status is zero and monitor the error before estimating a global motion model.

## Pipeline / 流程

The second frame is generated by a known 14x8 translation, giving the example a measurable expected motion. `status` marks points that survived tracking and `errors` supplies the per-point residual. The arrows are drawn on a BGR copy created by merging the tracked gray frame into three channels.

第二帧通过已知的 14x8 平移生成，因此结果具有可测的预期运动。`status` 标识跟踪成功的点，`errors` 提供每个点的残差；箭头绘制在通过三通道合并得到的 BGR 图像上。
