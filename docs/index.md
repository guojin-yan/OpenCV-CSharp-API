# OpenCV CSharp API

OpenCV CSharp API brings OpenCV 5.0.0 to .NET through a version-neutral managed API and stable native C ABI.

OpenCV CSharp API 通过版本中立的 managed API 和稳定的 native C ABI，把 OpenCV 5.0.0 带到 .NET。
