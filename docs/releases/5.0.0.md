# 5.0.0

Status: Stable / 状态：稳定版

## Summary / 概要

This first stable release strengthens diagnostics, everyday matrix access, image/video ergonomics, DNN detection postprocessing, runtime coverage, samples, and the controlled publication pipeline. Public availability is established only by the verified registries and matching GitHub Release.

本轮增强诊断、日常矩阵访问、图像与视频易用性、DNN 检测后处理、runtime 覆盖、案例教程和受控发布流程。公开可用状态只由核验通过的公共源与对应 GitHub Release 建立。

## Managed API / 托管接口

- `OpenCvSharpBuildInfo.NuGetPackageVersion` exposes the exact normalized package version separately from the native ABI version.
- `ColorConversionCodes` covers common BGR/RGB, alpha, grayscale, HSV, Lab, YUV, and Bayer conversions.
- `Mat` copies non-contiguous views row by row and adds row spans, `MatRowAccessor<T>`, OpenCV-compatible pixel vectors, `GetValue`/`SetValue`, and external-stride buffer copies.
- `ImageEncodingParam` keeps encoder keys and values paired; `VideoCapture.TryRead` and `TryRetrieve` make end-of-stream behavior explicit.
- DNN adds standard, rotated, class-aware batched, and Soft-NMS operations backed by OpenCV.
- `Point3d`, 16-bit pixel vectors, and dynamic-channel `MatType` factories fill common geometry and matrix-construction gaps.
- The OpenCV 5.0.0 `photo::ccm` source patch stores color-space state per model instead of through a reference to the process-wide sRGB object. The patch is applied before every runtime build and recorded in runtime-input provenance.

## Native ABI and runtimes / Native ABI 与运行时

- Full profile grows to 2,663 declared `jyppx_ocv_*` functions; all are mapped to managed imports. Mini remains at 527 functions.
- The managed/runtime split and matching-version rule remain unchanged.
- Runtime packages continue to be driven by the checked support contract; pending platforms are not presented as formally supported.

## Compatibility and migration / 兼容与迁移

- Public managed namespaces use `JYPPX.OpenCvSharp.*`; native entrypoints remain version-neutral `jyppx_ocv_*` identities.
- Existing array and flat integer encoder overloads remain available. New APIs are additive.
- Consumers should use `NuGetPackageVersion` for package diagnosis and native ABI values for managed/native compatibility checks.

## Validation / 验证

- Exact SDK multi-target managed builds cover .NET Framework 4.6-4.8.1, .NET Core 3.1, and .NET 5-10.
- Native build, CTest smoke, ABI export/binding maps, focused managed tests, sample builds, and repository invariants are required before commit.
- The structured Repository-signature verifier pins audited `NuGet.Packaging 7.6.0` and rejects unsigned, wrong-owner, or payload-drifted packages.
- Publication requires a reviewed candidate, NuGet.org repository-signature verification, GitHub Packages verification, and a matching GitHub Release.
