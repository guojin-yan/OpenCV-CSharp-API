# 5.0.0-preview.1

Status: Published / 状态：已发布

## Summary / 概要

The first public preview established the managed OpenCV 5 package and separately installable native runtime model.

首个公开预览版建立了 OpenCV 5 托管包与可独立安装的 native runtime 包模型。

## Managed API / 托管接口

- Introduced the initial managed modules for common matrix, image, video, geometry, calibration, and DNN workflows.
- Established disposable ownership for native-backed managed objects.

## Native ABI and runtimes / Native ABI 与运行时

- Introduced the native wrapper and the first public Windows x64 runtime package.
- Kept managed and runtime packages separate so applications install only the runtime matching their target.

## Compatibility and migration / 兼容与迁移

- This was the first public preview; later previews keep package and API identities version-neutral while extending the supported surface.

## Validation / 验证

- Package publication and the initial managed/runtime consumer path were verified for the public preview.
