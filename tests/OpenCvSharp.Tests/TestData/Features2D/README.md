# Features2D Test Data

This folder keeps guidance for code-generated feature test inputs.

本目录保存特征测试输入的生成策略说明。

Current rule:

当前规则：

- Prefer code-generated images over binary fixtures.
- Keep detector-specific shapes stable and simple.
- Do not depend on external assets unless a license and provenance are documented.

- 优先使用代码生成图像，而不是二进制测试资源。
- 保持检测器图案稳定、简单。
- 除非明确记录许可和来源，否则不要依赖外部资源。
